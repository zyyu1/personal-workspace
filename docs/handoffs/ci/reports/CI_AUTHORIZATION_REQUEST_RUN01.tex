\section{Limits and risks}
\begin{enumerate}[nosep]
  \item \textbf{CI is evidence, not acceptance.} It does not replace independent QA, browser QA, Windows host QA, or Design Window decisions. A green check must not be read as merge authorization.
  \item \textbf{Not a merge gate unless separately decided.} Making the check \emph{required} needs branch protection, which this private repository's plan does not expose (API 403). Proposal does not attempt it.
  \item \textbf{Environment difference.} CI runs on Linux; Windows-specific behaviour (e.g.\ native folder picker) remains out of scope.
  \item \textbf{Cost.} Private-repo Actions minutes count against the account's free quota; one run is expected to take a few minutes.
  \item \textbf{Action versions.} \texttt{actions/checkout@v4} and \texttt{actions/setup-node@v4} should be confirmed as current major versions before activation.
  \item \textbf{Lint warnings.} The 12 pre-existing Research warnings do not fail \texttt{eslint src} (exit 0); no lint rule change is proposed.
  \item \textbf{Push path.} The session proxy blocked the GitHub Contents API (HTTP 403) earlier; adding a workflow file via \texttt{git push} may additionally require a token with \texttt{workflow} scope. If the push is refused, execution will STOP and report.
\end{enumerate}
